# Лаба 5: Многопоточное программирование в C++

Все задачи демонстрируют работу с потоками (threads) в C++.

## Список задач:

### ✅ task1.cpp - Многопоточное суммирование вектора
**Что делает:**
- Создаёт большой вектор (10 млн элементов) со случайными числами
- Вычисляет сумму однопоточно (последовательно)
- Вычисляет сумму многопоточно (4 потока параллельно)
- Сравнивает время выполнения

**Ключевые концепции:**
- `std::thread` - создание потоков
- `std::mutex` - защита общих данных
- `std::lock_guard` - автоматическое управление мьютексом
- Разделение работы между потоками

**Как запустить:**
```bash
g++ -std=c++17 -pthread task1.cpp -o task1
./task1
```

---

### ✅ task2.cpp - Потокобезопасная очередь (Producer-Consumer)
**Что делает:**
- Реализует потокобезопасную очередь
- Один поток-производитель добавляет числа в очередь
- Три потока-потребителя извлекают и обрабатывают числа

**Ключевые концепции:**
- `std::queue` - очередь
- `std::condition_variable` - синхронизация потоков (ожидание событий)
- `std::unique_lock` - блокировка с возможностью освобождения
- Паттерн Producer-Consumer

**Как запустить:**
```bash
g++ -std=c++17 -pthread task2.cpp -o task2
./task2
```

---

### task3.cpp - Многопоточная обработка изображений
**Что делает:**
- Создаёт матрицу 1000x1000 пикселей (имитация изображения)
- Применяет фильтр размытия (blur) к каждому пикселю
- Сравнивает однопоточную и многопоточную обработку

**Ключевые концепции:**
- Обработка двумерных массивов
- Распределение строк изображения между потоками
- Фильтр размытия (усреднение соседних пикселей)

**Как запустить:**
```bash
g++ -std=c++17 -pthread task3.cpp -o task3
./task3
```

---

### task4.cpp - Вычисление числа π методом Монте-Карло
**Что делает:**
- Использует метод Монте-Карло для приближённого вычисления π
- Генерирует случайные точки и проверяет, попадают ли они в круг
- Использует `std::async` и `std::future` для параллельных вычислений

**Ключевые концепции:**
- `std::async` - асинхронное выполнение функций
- `std::future` - получение результата асинхронной операции
- Метод Монте-Карло
- Обработка исключений в асинхронных задачах

**Как запустить:**
```bash
g++ -std=c++17 -pthread task4.cpp -o task4
./task4
```

### task5.cpp - Пул потоков (Thread Pool)
**Что делает:**
- Реализует пул потоков для эффективного выполнения задач
- Вычисляет факториалы нескольких чисел параллельно
- Потоки переиспользуются для разных задач

**Ключевые концепции:**
- `std::packaged_task` - упаковка функции для асинхронного выполнения
- `std::bind` - связывание функции с аргументами
- Очередь задач
- Паттерн Thread Pool (переиспользование потоков)

**Как запустить:**
```bash
g++ -std=c++17 -pthread task5.cpp -o task5
./task5
```

## Основные концепции многопоточности:

1. **Потоки (Threads)** - параллельное выполнение кода
2. **Мьютексы (Mutex)** - защита общих данных от одновременного доступа
3. **Условные переменные (Condition Variables)** - синхронизация потоков
4. **Асинхронное программирование (async/future)** - получение результатов из потоков
5. **Пул потоков (Thread Pool)** - эффективное переиспользование потоков

---

## Зачем нужна многопоточность?

- **Увеличение производительности** на многоядерных процессорах
- **Параллельная обработка** больших объёмов данных
- **Отзывчивость** интерфейса (UI не зависает во время вычислений)
- **Эффективное использование** ресурсов компьютера
