# Лабораторная работа №6: Работа с базами данных в C++

## Структура проекта
```
Лаба 6/
├── include/          # Заголовочные файлы
├── src/              # Исходный код
├── tests/            # Unit-тесты
├── Makefile          # Сборка
└── university_db     # Исполняемый файл
```

## Запуск

### Компиляция
```bash
make
```

### Запуск программы
```bash
./university_db
```

### Запуск тестов
```bash
make test
```

### Очистка
```bash
make clean
```

## Описание

Интерактивная программа для работы с базой данных студентов и оценок.

**Реализовано:**
- Задание 1: Создание таблиц и настройка БД
- Задание 2: CRUD операции
- Задание 3: Транзакции и сложные запросы
- Задание 4: Валидация и безопасность
- Задание 5: Оптимизация и тестирование

**Технологии:** C++17, SQLite3, Google Test
